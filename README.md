# Shah Gee Jewellers — Premium Jewellery Website

A complete, production-ready e-commerce website for **Shah Gee Jewellers**, Lahore Cantt.

## 🚀 Quick Start

1. Open the `shah-gee-jewellers/` folder in **VS Code**.
2. Right-click `index.html` → **Open with Live Server** (install "Live Server" extension if needed).
3. Open `http://localhost:5500` in your browser.

No build tools, no npm install — pure HTML, CSS & JavaScript.
